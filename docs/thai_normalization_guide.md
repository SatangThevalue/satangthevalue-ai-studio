# 🇹🇭 คู่มือการปรับปรุงความแม่นยำภาษาไทย (Thai Text Normalization & Romanization)

ในการฝึกสอน (Fine-Tuning) โมเดล AI ด้านเสียง (TTS) ด้วยภาษาไทย ปัญหาหลักที่นักพัฒนาต้องเจอคือ **"ความกำกวมของการออกเสียง (Pronunciation Ambiguity)"** เนื่องจากภาษาไทยไม่มีการเว้นวรรคคำ และคำบางคำเขียนเหมือนกันแต่อ่านต่างกัน (เช่น เพลา -> เพ-ลา หรือ เพลา)

โปรเจกต์ SatangTheValue AI Studio ได้บูรณาการไลบรารี `PyThaiNLP` เพื่อแก้ปัญหานี้ในระดับ Data Preparation โดยรองรับ 2 โหมดหลัก:

## 1. Standard Mode (ตัดช่องว่าง)
- **หลักการทำงาน:** นำข้อความที่ Whisper ถอดมาได้ ไปผ่านการตัดคำ (Tokenization) ด้วย `pythainlp.tokenize.word_tokenize` และลบช่องว่าง (Whitespace) ออกทั้งหมด
- **ข้อดี:** ง่าย, รวดเร็ว, เหมาะสำหรับโมเดล TTS สมัยใหม่ (เช่น VITS, F5-TTS) ที่ตัว Base Model เคยเรียนรู้ภาษาไทยแบบปกติมาแล้วอย่างดี
- **ตัวอย่าง:** `สวัสดี ครับ วันนี้ อากาศ ดี` -> `สวัสดีครับวันนี้อากาศดี`

## 2. Karaoke / Romanization Mode (ภาษาคาราโอเกะ)
- **หลักการทำงาน:** แปลงอักขระภาษาไทยให้กลายเป็นตัวอักษรภาษาอังกฤษ (Romanization) ตามหลักเกณฑ์ราชบัณฑิตยสภา (Royal Thai General System of Transcription) ผ่านฟังก์ชัน `pythainlp.transliterate.romanize`
- **ข้อดี:** 
  - เพิ่มความแม่นยำให้โมเดล TTS ถึงขีดสุด! (Maximum Accuracy)
  - โมเดลไม่ต้องเดาการผสมสระหรือพยัญชนะไทยอีกต่อไป เพราะตัวอักษรภาษาอังกฤษมีการออกเสียงที่เป็นสากล
  - เหมาะสำหรับนำไป Fine-Tuning กับ Base Model ที่เป็นภาษาอังกฤษล้วนๆ (Cross-lingual Fine-tuning)
- **ตัวอย่าง:** `แมว` -> `maeo`, `สวัสดีครับ` -> `sawatdikrap`

## 🛠️ วิธีการใช้งานในโปรเจกต์
1. ไปที่เมนู **Tab 2.1 Data Prep (ล้างเสียง)**
2. ขยายเมนู **ตั้งค่าขั้นสูง (Auto-Transcription Settings)**
3. ในช่อง **รูปแบบข้อความภาษาไทย** ให้เลือก `Karaoke (คาราโอเกะ / Romanization)`
4. เมื่ออัปโหลดไฟล์เสียง ระบบจะทำการสร้าง `metadata.csv` เป็นภาษาคาราโอเกะให้โดยอัตโนมัติ พร้อมส่งเข้ากระบวนการ Training ทันที!
